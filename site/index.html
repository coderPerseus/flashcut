说一句话，剪好一条视频

闪剪是一款开源的 macOS 视频剪辑应用。打开任意视频，告诉它“只保留击杀和团战，控制在 5 分钟以内”，它会逐段看完视频、挑出片段、加上动效并导出。还能自动校对字幕。

下载 macOS 版 在 GitHub 查看源码

支持 Apple 芯片和 Intel 的 Mac（macOS 12 及以上）· 免费开源

用说的来剪视频

视频理解基于 Cloudflare Clef 决策模型：每一段画面和声音都会被逐一判断，再按你的要求取舍。

💬

聊天剪辑

“去掉回放”“3:20 到 4:10 不要”“再短一点”“撤销”——像和剪辑师说话一样修改成片。

🧩

剪辑模板

内置电竞、体育、访谈播客、Vlog、课程模板，也能把自己的要求存成模板、导入导出分享。

⚡️

Remotion 动效

导出时自动加开场标题、节点转场、“高能”时刻和片尾卡片，节点来自模板。

📝

字幕校对

对照语音或画面里的字幕，逐条找出错字、错名和串行，用小模型给出修改，人工确认后导出。

🔍

精细时间线

时间线可缩放到 0.1 秒，框选任意范围保留或剪掉；按保留、剪掉、待分析过滤查看。

🔑

用你自己的模型

聊天和纠错支持 OpenAI 兼容和 Anthropic 协议：API 中转站、阿里云百炼、DeepSeek、本机 Ollama 都可以。

安装

大约 5 分钟。闪剪本身免费，分析视频时调用 Cloudflare Workers AI，按量计费（48 分钟的比赛约 $0.12）。

  1. 下载并拖进“应用程序”

    下载 FlashCut-macOS.dmg，打开后把“闪剪”拖进“应用程序”文件夹。

  2. 第一次打开

    安装包暂时没有苹果签名，第一次请在“应用程序”里右键点“闪剪” → 打开 → 打开。如果提示“已损坏”，在终端运行：

    xattr -dr com.apple.quarantine /Applications/闪剪.app

  3. 安装 ffmpeg

    闪剪用 ffmpeg 切片和导出。用 Homebrew 安装：

    brew install ffmpeg

  4. 连接 Cloudflare

    二选一：

    · 用 Cloudflare 官方命令行登录（闪剪会自动检测到）：

    npm i -g cf
cf auth login

    · 或在 Cloudflare 后台创建一个有 Workers AI 权限的 API Token，然后在闪剪「设置 → 模型」里填入 Account ID 和 Token，点“测试连接”。

  5. （可选）动效和自己的模型

    导出动效需要 Node.js 18+，第一次使用会自动安装渲染引擎。想用自己的聊天或纠错模型，在「设置 → 模型 → 添加服务」填 Base URL 和密钥即可。

开始使用

  1. 打开视频：点“打开视频”，或直接把视频拖进窗口。
  2. 说要求：在右侧聊天里说想怎么剪，或在工具栏「剪辑要求」里套用模板、点“智能剪辑”。
  3. 调整：时间线上点选或框选片段，手动保留 / 剪掉；勾“只看成片”直接预览。
  4. 导出：点“导出”，选择是否加动效、画质和保存位置。
  5. 字幕校对：切到顶部的“字幕校对”，选视频和 SRT / VTT / ASS 字幕，开始校对后逐条确认修改并导出。

快捷键：⌘O 打开 · ⌘E 导出 · ⌘Z 撤销 · ⌘= / ⌘− 缩放时间线 · 空格 播放

常见问题

视频会上传到哪里？

视频留在你的电脑上。分析时，闪剪把每一小段压缩成低清晰度的片段发给 Cloudflare Workers AI 判断，Cloudflare 表示不会存储或用这些请求训练模型。导出完全在本机完成。

为什么用 Cloudflare Clef？和 Jev 有什么关系？

Clef 是“决策模型”：不生成文字，而是对一组问题给出带概率的答案，快且便宜，非常适合“这一段要不要留”这类判断。它与 TypeSafe 的 Jev 接口兼容，Clef-omni 还能看视频、听声音。

判断准吗？

每段按整段打分，短暂的瞬间可能漏判或误判。闪剪会显示每段命中的要求和把握度，低于 60% 的会标“可能”；你可以调灵敏度、框选范围手动修正。

支持 Windows 吗？

目前只发布了 macOS 版。代码基于 MyGo，可以跨平台编译，欢迎在 GitHub 提需求或贡献。
